============================================================
  FACE MATCHING - PYINSTALLER BUILD COMMAND
  Target: Windows Server with NVIDIA GPU (CUDA 12.x / cu128)
============================================================


STEP 1 - DISCOVER YOUR ACTUAL CUDA DLL FILENAMES + PATH
------------------------------------------------------------
Before building, run this on the server inside the same venv
you will build from. It tells you the exact DLL filenames
and the venv torch/lib path you need.

python -c "import torch, os; lib=os.path.join(os.path.dirname(torch.__file__),'lib'); print('LIB DIR:', lib); [print(f) for f in sorted(os.listdir(lib)) if f.endswith('.dll')]"

Expected output (filenames may vary by PyTorch version):
    cudart64_12.dll
    cublas64_12.dll
    cublasLt64_12.dll
    cudnn64_9.dll
    nvrtc64_120_0.dll
    ...

Copy the LIB DIR path and the exact DLL filenames into the
build command below.


STEP 2 - REPLACE THESE PLACEHOLDERS IN THE COMMAND
------------------------------------------------------------
    <TORCH_LIB>        -> the LIB DIR from Step 1
                          e.g. C:\FaceMatching\venv\Lib\site-packages\torch\lib
    cudart64_12.dll    -> verify exact name from Step 1
    cublas64_12.dll    -> verify exact name from Step 1
    cudnn64_9.dll      -> verify exact name from Step 1 (was cudnn64_8 in old build)
    nvrtc64_120_0.dll  -> verify exact name from Step 1


STEP 3 - RUN FROM YOUR PROJECT ROOT (where scheduler.py lives)
------------------------------------------------------------

pyinstaller --noconfirm --onedir --console --clean --name FaceMatching --hidden-import=torch --hidden-import=torchvision --hidden-import=facenet_pytorch --hidden-import=cv2 --hidden-import=PIL --hidden-import=pyodbc --hidden-import=apscheduler --hidden-import=apscheduler.schedulers.blocking --hidden-import=concurrent_log_handler --hidden-import=settings --hidden-import=logger_setup --hidden-import=dotenv --collect-all torch --collect-all torchvision --collect-all facenet_pytorch --collect-all cv2 --collect-all skimage --collect-all pywin32 --collect-submodules pywintypes --add-binary "<TORCH_LIB>\cudart64_12.dll;." --add-binary "<TORCH_LIB>\cublas64_12.dll;." --add-binary "<TORCH_LIB>\cudnn64_9.dll;." --add-binary "<TORCH_LIB>\nvrtc64_120_0.dll;." scheduler.py


STEP 4 - VERIFY THE OUTPUT
------------------------------------------------------------
After build completes, you will find:

    dist\FaceMatching\
        FaceMatching.exe
        _internal\        (all bundled deps + CUDA DLLs)
        ...

Test it:
    cd dist\FaceMatching
    FaceMatching.exe

You should see your scheduler banner and logs/ + log_archive/
folders being created.


============================================================
  WHAT CHANGED VS THE OLD COMMAND
============================================================

REMOVED:
  --onefile                     (re-extracts multi-GB on every launch; slow cold-start)
  --hidden-import=easyocr       (commented out in code)
  --collect-all easyocr         (commented out in code)
  hardcoded C:\AIPhotoMatchexe  (machine-specific path; now placeholder)
  cudnn64_8.dll                 (cuDNN 8 - mismatched with CUDA 12; replaced with cudnn64_9.dll for cu128)

ADDED:
  --onedir                      (folder output; instant startup; easy patching)
  --clean                       (clear stale build cache first)
  --name FaceMatching           (clean output name)
  --hidden-import=pyodbc        (binary ext - PyInstaller can miss it)
  --hidden-import=apscheduler   (was missing - scheduler entry deps)
  --hidden-import=apscheduler.schedulers.blocking
  --hidden-import=concurrent_log_handler  (used by logger_setup.py)
  --hidden-import=logger_setup  (string-imported by scheduler.py)
  --collect-all torchvision     (some PyTorch ops need it)
  --collect-all skimage         (scikit-image has many submodules)


============================================================
  IMPORTANT - NOT BUNDLED, MUST BE PRESENT AT RUNTIME
============================================================

  1. .env file                  -> place next to the exe
  2. logs\ folder               -> created at runtime, exe needs write access
  3. log_archive\ folder        -> created at runtime, exe needs write access
  4. MS ODBC Driver for SQL Server  -> install separately on the server
                                       (must match driver name in .env)
  5. NVIDIA driver              -> already on server, not bundled
